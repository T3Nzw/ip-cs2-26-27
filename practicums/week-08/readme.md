# Седмица 8 - Динамична памет и обработка на грешки

## 1. Stack и Heap
1. Stack (Стек): 
    - Заделянето на памет става **по време на компилацията** на програмата;
    - Паметта се освобождава **автоматично** при напускане на стековата рамка/областта на идентификатори, в която е дефинирана.
    - Кога? `Данни, чиито обем е ясен преди компилация!`
2. Heap (Куп):
    - Заделянето на памет става **по време на изпълнението** на програмата;
    - Паметта се освобождава **ръчно** от програмиста.
    - Кога? `Данни, чиито обем НЕ е ясен преди компилация!`

## 2. Заделяне и освобождаване
- Статична памет:
```cpp
bool check = true; /* {Статична}: Заделя се една клетка с размер sizeof(bool)  */

if (check) {
    int nums[10]; /* {Статична}: Заделят се 10 на брой клетки с размер sizeof(int)  */
} /* Освобождават се 10 на брой клетки с размер sizeof(int) */
```
- Динамична памет
```cpp
size_t size; /* {Статична}: Заделя се една клетка с размер sizeof(size_t) */
char answer; /* {Статична}: Заделя се една клетка с размер sizeof(char) */
std::cin >> size >> answer;
int* nums; /* {Статична}: Заделя се една клетка с размер "указател"  */

if (answer == 'n') {
    nums = new int[size]; /* {Динамична}: Заделяме size на брой клетки с размер sizeof(int) */
} /* !!! Паметта НЕ СЕ освобождава !!! */
else {
    nums = new int[size * 2]; /* {Динамична}: Заделяме size на брой клетки с размер sizeof(int) */
} /* !!! Паметта НЕ СЕ освобождава !!! */

    /*{Статична}: Заделя се една клетка с размер sizeof(size_t)*/
for (size_t idx = 0; idx < size; ++idx) {
    std::cin >> nums[idx];
} /* Освобождават се  клетка с размер sizeof(size_t) */

    /*{Статична}: Заделя се една клетка с размер sizeof(size_t)*/
for (size_t idx = 0; idx < size; ++idx) {
    std::cout << nums[idx] << ' ';
} /* Освобождават се  клетка с размер sizeof(size_t) */
std::cout << std::endl;

delete[] nums; /* Освобождаваме size на брой клетки с размер sizeof(int) */
```
- Всеки оператор `new` трябва да има кореспондиращ `delete`/`delete[]`. В противен случай получаваме *memory leak*!
- Паметта се освобождава само веднъж! (`delete` не е препоръчително да се вика два пъти върху една и съща променлива)

- Освен показаното заделяне на масив имаме и такова за "проста" променлива:
```cpp
double* num = new double(3.14); /* Подаваме стойността, която да се запише */
delete num; /* Освобождаваме една клетка с размер sizeof(double) */

std::cout << *num << std::endl; /* !!! Undefined behaviour - Тази памет не е "наша" !!! */
```
- Има и динамични многомерни масиви:
```cpp
size_t size;
std::cin >> size;
char** matrix = new char*[size];
for (size_t row = 0; row < size; ++row) {
    matrix[row] = new char[size];
    for (size_t col = 0; col < size; ++col) {
        std::cin >> matrix[row][col];
    }
}

for (size_t row = 0; row < size; ++row) {
    for (size_t col = 0; col < size; ++col) {
        std::cout << matrix[row][col] << ' ';
    }
    std::cout << std::endl;

    /* Преди да освободим масива от указатели, трябва да освободим паметта, към която сочат */
    delete[] matrix[row]; 
}

delete[] matrix;
```

## 3. Грешки
- Понякога искаме да прекратим действието на (част от) програмата по лесен за разбиране начин, без това да променя (много) самата сигнатура на кода.
- `assert(<condition>);` -- Гърми при `<condition> == false`:
```cpp
#include <cassert> // Трябва да се добави библиотеката cassert

bool condition = true;
assert(condition);
assert(!condition); // Assertion failed: (!condition)
```

- `try {...} catch (<exception>) {...}` -- "*Пробва*" кода поставен в тялото на `try`. Ако бъде прихваната грешка от типа на `<exception>` (или негов подклас) влиза в тялото на отговарящия `catch` блок. Ако не се прихване грешка, не се изпълнява нито едно `catch` тяло.
- `throw <exception>` -- "*Хвърля*" грешка. `<exception>` е от тип [std::exception](https://en.cppreference.com/cpp/error/exception). Ако съответната грешка не се прихване от `try catch` оператор, то тя прекратява програмата.
- `<exception>.what()` ни дава достъп до съобщението на грешката.
```cpp
# include <iostream>

void iWillThrowAnException() {
    throw std::logic_error("Просто не те харесвам :(");
}

int main() {
    try {
        iWillThrowAnException();
    } catch (const std::logic_error& e) {
        std::cout << "Прихваната грешка: " << e.what() << std::endl;
    }
    
    return 0;
}
```
```cpp
#include <iostream>

void iWillThrowAnExceptionYouWouldNotHandle() {
    throw std::runtime_error("Този път със сигурност не ме хващаш 0v0");
}

int main() {
    try {
        iWillThrowAnExceptionYouWouldNotHandle();
    } catch (const std::logic_error& e) {
        std::cout << "Прихваната грешка: " << e.what() << std::endl;
    } catch (const std::bad_function_call& e) {
        std::cout << "Прихваната грешка: " << e.what() << std::endl;
    }
    
    return 0;
}
```
- Изход: `libc++abi: terminating due to uncaught exception of type std::runtime_error: Този път със сигурност не ме хващаш 0v0`
