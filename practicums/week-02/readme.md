# Седмица 2 - Условни оператори

## 1. Булеви стойности
- В булев израз следните стойности се оценяват до `false`
    - `false`; `0`; `0.0`; `nullptr`; `\0`
- Всички останали се оценяват до `true`

## 2. Оператор `if`
- Ако `<condition>` се оцени като `true` ще се изпълни тялото на оператора
```cpp
if (<condition>)
    // тяло

if (<condition>) {
    /* 
    тяло: ред_1
    ...
    тяло: ред_n 
    */
}
```

## 3. Оператор `if-else`
- Ако `<condition>` се оцени като `true` се изпълнява тялото на `if`, иначе се изпълнява тялото на `else`
```cpp
if (<condition>) 
    // тяло на if
else
    // тяло на else

if (<condition>) {
    /* 
    тяло на if: ред_1
    ...
    тяло на if: ред_n 
    */
} else {
    /* 
    тяло на else: ред_1
    ...
    тяло на else: ред_n 
    */
}
```

## 4. Вложен оператор `if-else-if-...-else`
- Можем да влагаме условните оператори, като по този начин да правим по-сложни проверки
```cpp
if (<condition_1>) {
    // condition_1 == true
} else {
    if (<condition_2>) {
        // condition_1 == false, condition_2 == true
    } else {
        if (<condition_3>) {
            // condition_1 && condition_2 == false, condition_3 == true
        } else {
            if (<condition_4>) {
                // condition_1 && condition_2 && condition_3 == false, condition_4 == true
            } else {
                // condition_1 && condition_2 && condition_3 && condition_4 == false
            }
        }
    }
}
```

## 5. Оператор `switch`
- Ако имаме повече от 2 вложени `if-else` оператора, в общия случай, използваме оператора `switch`.
```cpp
switch(<expresssion>) {
    case <value_1>: 
        /* <expression> == <value_1> */
        break;
    //...
    case <value_n>:
        /* <expression> == <value_n> */
        break;
    default:
        /* <expression> does not equal any listed value */
        break;
}
```
- Ако `<expression>` е от тип `bool` ще има само два възможни случая!
- `<value_i>` трябва да е константа, литерал или изборен тип (`enum`).
- Случаите се проверяват по реда на изписаване. В момента на съвпадение (`<expression> == <value_i> -> true`) се изпълняват всички случаи от `case <value_i>` надолу. Ако искаме да се изпълни само до определен случай, можем да прекъснем операцията с ключовата дума `break`.
- `default` не е задължителна част от оператора.

## 6. Тернарен оператор `?:`
```cpp
<condition> ? <expression_if> : <expression_else>
```
- Ако условието се оцени като `true` се ипълнява `expression_if`, иначе се изпълнява `expression_else`
- Пример: Какво ще изведе следния програмен фрагмент
```cpp
int a = 1, b = 0;
int c = (a-- == b || ++b) && (a++ || a-- == b) && (--a == b|| b--) ? ++a : b--;
std::cout << "a: " << a << ", b: "<< b << ", c: " << c << std::endl;
```

## Задача 12 - Римски цифри

| Арабски | Римски |
|---------|--------|
|1        |I       |

## Задача 13 - Бакалия
Трендафил е мениджър логистика на местната бакалия. В ролята си на мениджър логистика, той трябва редовно да обикаля магазина и да проверява дали всички стоки са в срок на годност. За да не се налага да проверява ръчно срокът на годност на всеки един продукт, той решил да го кодира в баркодовете им. Има само един проблем... Трендафил не разбира от компютри и затова наема Вас да напишете програма, която приема баркод - положително 6 цифрено число, и преди колко дена е зареден. Програмата трябва да отпечатва на екрана дали въведеният продукт е в срок на годност. За кодовете важат следните правила:
- Първата цифра определя вида на продукта
    - `1xxxxx` е код за месни продукти;
    - `2xxxxx` е код за млечни продукти;
    - `3xxxxx` е код за тестени продукти;
    - `4xxxxx` e код за плодове и зеленчуци.
- Как определяме дните на годност
    - Месни продукти: abs(`цифра2` `цифра4` - `цифра3`*`цифра5`);
    - Млечни продукти: floor(((`цифра3`+ `цифра5`) / 2) + `цифра2`);
    - Тестени продукти: abs(`цифра2` + `цифра4` - `цифра6`);
    - Пловоде и зеленчуци: floor((`цифра3` + `цифра4` + `цифра6`) / 3).

Примери:
- Вход: `246315 6`; Изход: `Да`; Обяснение: Кодът е от вида `2xxxxx`, следователно продуктът е мечен. Заместваме floor((6 + 1)/2 + 4) = 7, следователно продуктът е годен за употреба 7 дена след зареждане. Трендафил го е заредил преди 6 дена, следователно продуктът все още е в срок на годност.
- Вход: `109197 81`; Изход: `Не`; Обяснение: Кодът е от вида `1xxxxx`, следователно продуктът е месен. Заместваме abs(01 - 9*9) = 80, следователно продукът е годен за 80 дена след зареждане. Трендафил го е заредил преди 81 дена, следователо продуктът е с изтекъл срок на годност.

Note: Приемаме входните данни за валидни (винаги е 6 цифрено положително цяло число)
