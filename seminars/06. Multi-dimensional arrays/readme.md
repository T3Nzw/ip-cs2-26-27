# Многомерни масиви

Досега разгледахме едномерните масиви, които представляват линейна последователност от елементи. Често обаче се налага да съхраняваме и обработваме данни, които са организирани в табличен вид (в редове и колони) – например математически матрици, шахматни дъски или етажи и стаи в сграда. За целта използваме многомерни масиви, като най-често срещаните сред тях са двумерните масиви.

## Двумерни масиви

Двумерният масив може да се разглежда като „масив от масиви“ или като таблица с предварително фиксиран брой редове и колони.

## Синтаксис за дефиниране

Синтаксисът за дефиниране на двумерен масив надгражда този на едномерните, като добавя още едно измерение (брой редове и брой колони):
C++

// Дефиниция без инициализация
```cpp
// rows и cols са константни по време на компилация
int arr[rows][cols];
```

// Дефиниция с инициализация
```cpp
int arr2[rows][cols] = {
    {1, 2, 3},
    {4, 5, 6}
};
```

където:

- rows е броят на редовете (задължително се знае по време на компилация);

- cols е броят на колоните (също се знае по време на компилация).

Пример за конкретен двумерен масив (матрица) с 2 реда и 3 колони:

```cpp
int matrix[2][3] = {
    {10, 20, 30},
    {40, 50, 60}
};
```

В паметта на компютъра елементите на двумерния масив отново се разполагат последователно (линейно) – първо се описват елементите на първия ред, след това на втория и т.н.
Достъп до елементи и индексиране

Всеки елемент в двумерен масив се идентифицира с два индекса:

- Индекс на реда (обикновено се означава с i или row);

- Индекс на колоната (обикновено се означава с j или col).

И индексите на редовете, и тези на колоните започват от 0.

```cpp
int matrix[2][3] = {
    {10, 20, 30},
    {40, 50, 60}
};

// Взимаме елемента на 0-ти ред и 1-ва колона (стойността 20)
int val = matrix[0][1]; 

// Промяна на стойност
matrix[1][2] = 99; // заменя 60 с 99 в последния ред и колона
```

## Обхождане на двумерен масив с цикли

Тъй като имаме две измерения (редове и колони), за обхождането на всички елементи най-често използваме вложени цикли (nested loops) – външен цикъл за редовете и вътрешен цикъл за колоните.

Пример за четене на данни от стандартния вход и принтиране на двумерен масив:

```cpp
#include <iostream>

constexpr unsigned ROWS = 3;
constexpr unsigned COLS = 4;

int main() {
    int matrix[ROWS][COLS];

    // Въвеждане на елементите от конзолата
    for (unsigned i = 0; i < ROWS; ++i) {
        for (unsigned j = 0; j < COLS; ++j) {
            std::cin >> matrix[i][j];
        }
    }

    // Извеждане (принтиране) на двумерния масив като таблица
    for (unsigned i = 0; i < ROWS; ++i) {
        for (unsigned j = 0; j < COLS; ++j) {
            std::cout << matrix[i][j] << " ";
        }
        std::cout << std::endl; // нов ред след края на всеки ред от матрицата
    }

    return 0;
}
```

## Подаване на двумерни масиви като аргументи на функции

Подобно на едномерните масиви, когато подаваме двумерен масив на функция, той също претърпява array-to-pointer decay. За да може компилаторът правилно да изчислява паметта и адресите на елементите, размерът на колоните (най-малкото) е задължително да бъде указан в сигнатурата на функцията. Броят на редовете може да бъде пропуснат или също подаден като отделен параметър.

Пример за функция, която приема двумерен масив и го принтира:

```cpp
// Размерът на колоните (COLS) е задължителен в сигнатурата!
void printMatrix(int matrix[][4], unsigned rows, unsigned cols) {
    for (unsigned i = 0; i < rows; ++i) {
        for (unsigned j = 0; j < cols; ++j) {
            std::cout << matrix[i][j] << " ";
        }
        std::cout << std::endl;
    }
}

int main() {
    int myMat[2][4] = {
        {1, 2, 3, 4},
        {5, 6, 7, 8}
    };

    printMatrix(myMat, 2, 4);
    return 0;
}
```

## N-мерни масиви

Логиката за двумерните масиви може да се разшири до произволен брой измерения (тримерни масиви, четиримерни и т.н.).

Например тримерен масив (който може да си представим като „куб“ от данни или „том с книги, съдържащи страници и редове“) се дефинира така:

```cpp
// 3 блока, всеки с по 4 реда и 5 колони
int cube[3][4][5];
```

За обхождането на тримерен масив ще са ни нужни три вложени цикъла:

```cpp
for (unsigned i = 0; i < 3; ++i) {
    for (unsigned j = 0; j < 4; ++j) {
        for (unsigned k = 0; k < 5; ++k) {
            cube[i][j][k] = i + j + k; // примерна операция
        }
    }
}
```

С увеличаването на броя измерения паметта, която масивите заемат, нараства лавинообразно и силно се усложнява тяхното управление в статичната памет, поради което при по-сложни структури в практиката често се прибягва към динамично заделяне на памет или използване на стандартни контейнери.
