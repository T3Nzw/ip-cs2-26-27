# Едномерни масиви

Нека да си представим, че ни е дадена следната задача:
трябва да напишем програма, която да чете `N` на брой
цели числа от стандартния вход (`N` е предварително фиксирано)
и да намира средноаритметичната стойност на тези числа.

За да решим тази задача със знанията ни досега, бихме използвали
целочислени променливи:

```cpp
#include <iostream>

constexpr unsigned N = ...; // конкретната стойност не е от значение

int main() {

  int x1, x2, x3, ..., x10, x11, ... xn;
  std::cin >> x1 >> x2 >> x3 >> ... >> x10 >> x11 >> ... >> xn;

  int sum = x1 + x2 + x3 + ... + x10 + x11 + ... xn;

  double avg = (double)sum / N;

  return 0;
}
```

Очевидно е, че горното би станало изключително трудоемко за голяма
стойност на `N`. Как тогава бихме могли да се справим с горния проблем?

## Масиви

Масивът е редица от стойности от някакъв тип, които са разположени
**последователно** в паметта. Този тип на стойностите *трябва* да бъде
един и същи за всяка стойност в масива.

Синтаксисът за дефиниране на масив е следният:

```cpp
// дефиниция без инициализация
T arr[N];
// дефиниция с инициализация
T arr2[N] = {x1, x2, ..., xN};
// това отново е дефиниция с инициализация
T arr2[N] {x1, x2, ..., xN};
```

където `T` е някакъв конкретен тип (`int`, `bool`, `double *` и др.),
`arr` е името (идентификаторът) на масива, а `N` е стойност, **която
задължително се знае по време на компилация**.

Колекции, чиито елементи са от един и същи тип, се наричат хомогенни.
В частност, масивите са хомогенни колекции (не говорим за класове/обекти).

Ето пример за дефиниция на конкретен масив от 5 целочислени стойности:

```cpp
int arr[5] = {5, 1, 3, 9, 3};
```

За него можем да си мислим, че се представя в паметта по следния начин:

```
arr
|
v

+---+---+---+---+---+
| 5 | 1 | 3 | 9 | 3 |
+---+---+---+---+---+
```

и елементите **винаги** са последователно разположени. Това е изключително
важно свойство на масивите. Тъй като елементите са последователни, можем
за всеки елемент да определим някаква позиция - или иначе казано, **индекс**.
Обикновено в езиците за програмиране това индексиране започва от 0, а не от 1,
както в математиката (изключение правят езици като Lua). Тоест, имаме следното:

```
arr
|
v

  0   1   2   3   4   <- индекси
+---+---+---+---+---+
| 5 | 1 | 3 | 9 | 3 |
+---+---+---+---+---+
```

Тъй като индексите са уникални ключове, определящи кой е даденият елемент в масива,
можем да ги използваме, за да вземем елемент на определена позиция:

```cpp
int arr[5] = {5, 1, 3, 9, 3};

int x2 = arr[1];

std::cout << x2 << std::endl;
std::cout << arr[0] << arr[4] << std::endl;

// имаме ли елемент на индекс 5?
std::cout << arr[5] << std::endl;
```

Нека забележим, че в масива имаме само 5 елемента,
тоест индексите са 0, 1, 2, 3, 4. Следователно би било
логично да нямаме елемент на 5-ия индекс.

Това обаче не е съвсем така. Всичките елементи в масива
са последователни в паметта и абсолютно нищо не пречи
и последният елемент да се следва от някаква друга стойност.
Тази стойност, обаче, сама по себе си не е част от масива.
Така че, дори и да я има, не бихме искали да я достъпваме,
използвайки масива. Горният израз `arr[5]` е **недефинирано
поведение** - може да доведе до грешка, може да принтира
garbage стойност, а може и да се случи друго. **НИКОГА**
не бихме искали да излизаме от границите на масива.

---

Нека се върнем обратно на първоначалната ни задача.
Как такъв масив ни помага да намерим средноаритметичното
на N числа? Бихме могли да напишем следното:

```cpp
#include <iostream>

constexpr unsigned N = ...;

int main() {

  int arr[N];
  std::cin >> arr[0] >> arr[1] >> ... >> arr[N-1];

  int sum = arr[0] + arr[1] + ... arr[N-1];

  double avg = (double)sum / N;

  return 0;
}
```

но това пак не ни спестява много писане. Тъй като между
различните изрази за индексиране на елементи имаме както
общ фактор (`arr[...]`), така и променящ се такъв (стойността на индекса),
който е също така и последователен, бихме могли да използваме цикли,
за да направим едно и също действие върху всеки от елементите на масива
`N` на брой пъти:

```cpp
#include <iostream>

constexpr unsigned N = ...;

int main() {

  int arr[N];

  int sum = 0;
  for(int index = 0; index < N; ++index) {
    std::cin >> arr[index];
    sum += arr[index];
  }

  double avg = (double)sum / N;

  return 0;
}
```

Така на всяка итерация на цикъла въвеждаме стойност от стандартния вход,
добавяме я към сумата и продължаваме към следващия елемент, ако има такъв.

**Циклите са основния начин да обхождаме елементите на масив**.

Разбира се, можехме да го направим и с `while` цикъл:

```cpp
#include <iostream>

constexpr unsigned N = ...;

int main() {

  int arr[N];

  int sum = 0;

  int index = 0;
  while (index < N) {
    std::cin >> arr[index];
    sum += arr[index];

    index++;
  }

  double avg = (double)sum / N;

  return 0;
}
```

## Подаване на масиви като аргументи на функции

Можем да подаваме едномерни масиви като аргументи
на функции по следните два начина, които в случая
правят едно и също:

```cpp
void printElements(int arr[]);
void printElements2(int *arr);
```
